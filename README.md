# Unlimited Mirrors For ChilloutVR
![Unlimited.gif](Unlimited.gif)

Removes the limit of 4 spawnable portable mirrors and just lets you go crazy


If you encounter issues with this mod, feel free to contact me on Discord (Malthbern)!

## Install/Usage
Install [MelonLoader](https://github.com/HerpDerpinstine/MelonLoader) version 0.7.2-ci.2325 or higher, this is required as the mod has been updated specifically for 0.7.2-ci.2325!

Download the latest release from [Releases](https://github.com/Malthbern/UnlimitedMirrors/releases) and place in your ChilloutVR/Mods folder!
